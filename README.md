## VER 3.6.0 — 오답노트 및 필기 저장 개선 (테스트 배포)
- 메인 오답노트: 새 채점 오답 자동 등록, 기존 모의고사 오답 가져오기, 내 답/정답/해설, 메모, 다시 풀기, 유사 유형 연습, 연속 3회 정답 기준, 신규 채점 통계, 교재 직접 등록 및 펜슬 풀이.
- 기존 암산의 오답 여부 및 누적 통계는 유지하지만, 과거 실제 입력 답안은 저장된 적이 없어 복구할 수 없음. 과거 암산 오답은 기존 암산 복습 메뉴에서 이용. 교재 직접 등록 문제는 동일 문제 재풀이만 지원.
- 필기: IndexedDB로 자동 이전. 이전 성공 및 내용 일치 확인 후 기존 localStorage 원본 제거. 충돌 시 기존 원본을 남김. JSON 백업/복원(동일 페이지 교체), 저장 사용량 표시. 과거 저장 실패 후 이미 유실된 획은 복구 불가. 이전 전 반드시 기존 JSON 백업을 저장할 것.
- 오답노트는 기존 계정별 localStorage 및 Supabase 동기화 구조 사용. 오답노트 필기와 메모도 동기화 payload에 포함되며, 매우 큰 노트는 localStorage 용량 제한이 남음. 기존 문제풀이 용지 필기는 기기 전용.
- Supabase SQL Editor에서 `upgrade_360.sql`을 먼저 실행. 기존 `setup.sql`을 다시 실행하지 말 것. 기존 RLS 정책과 데이터는 유지. 기존 동기화는 전체 레코드 교체 방식이므로 여러 기기에서 동시에 수정하지 말고 홈에서 최신 기록을 불러온 뒤 작업할 것.
- 배포: ZIP의 파일 9개(HTML 5개, JS 2개, README 및 SQL)를 저장소에 업로드. config.js, theme.css, icon.png, setup.sql은 기존 파일 유지. SQL은 GitHub 업로드만으로 실행되지 않음.
- 검증: JavaScript 문법 검사 완료. 브라우저 실행 검증은 환경의 관리자 차단으로 완료하지 못함. 실제 iPad 및 Supabase 연결 테스트 필요.
