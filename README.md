# GSAT STUDY MASTER

GSAT 암산 훈련 · 실전 모의고사 · 유형별 연습 · 문제풀이 용지

## VER 3.5.0
- 문제풀이 용지: Notability 스타일 전체 화면, 상단 아이콘 툴바, 페이지 미리보기, 타이머
- 펜 색상/굵기/필압, 형광펜 투명도, 부분/획 단위 지우개, 실행 취소/다시 실행
- 무지/모눈/줄노트/GSAT 용지, 두 손가락 확대/축소 및 이동, 펜슬 전용 모드
- 기존 4개 영역, 40문항(7페이지), 정답 입력, PNG 저장/인쇄, 로컬 저장 키 유지
- 용지 변경은 페이지별 적용. 자유 용지는 기존 6개 필기 캔버스를 유지하고 번호/정답란을 숨김.
- 필기 JSON 백업 다운로드 (가져오기 기능은 미구현)
- 암산/모의고사/클라우드 동기화 코드는 변경하지 않음.

### 배포
`paper.html`, `index.html`, `README.md` 3개 파일을 저장소 루트에서 교체합니다. 다른 파일은 유지합니다. 동일한 GitHub Pages 주소에서 기존 `gsat-paper-v1` 로컬 데이터를 읽습니다. 기존 파일을 삭제하거나 브라우저 사이트 데이터를 지우지 마세요. 필기 기록은 Supabase에 동기화하지 않습니다.

### 확인 필요
실제 iPad Safari / 홈 화면 앱에서 Apple Pencil 필압, 손바닥 인식, 두 손가락 제스처, PNG 다운로드 및 인쇄를 확인합니다. OS 수준의 손바닥 판별을 보장하지 않습니다.
